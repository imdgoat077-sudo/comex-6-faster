Key research papers on multi-agent orchestration, grouped by focus:

### Surveys and Taxonomies
* [Large Language Model based Multi-Agents: A Survey of Progress and Challenges](https://arxiv.org/abs/2402.01680) (Guo et al., 2024, IJCAI). Foundational survey categorizing agent profiling, multi-agent communication environments, and skill growth mechanisms.
* [Multi-Agent Collaboration Mechanisms: A Survey of LLMs](https://arxiv.org/abs/2501.06322) (Tran et al., 2025). Presents a five-dimensional orchestration taxonomy: actors, interaction types (cooperation, competition, coopetition), structures (peer-to-peer, centralized, distributed), strategies (role-based, model-based), and coordination protocols.
* [A survey on LLM-based multi-agent systems: workflow, infrastructure, and challenges](https://doi.org/10.1007/s44336-024-00009-2) (Li et al., 2024, *Vicinagearth*). Categorizes orchestration infrastructure and workflows across five components: profile, perception, self-action, mutual interaction, and evolution.
* [LLM-Based Multi-Agent Orchestration: A Survey of Frameworks, Communication Protocols, and Emerging Patterns](https://doi.org/10.3390/fi18060326) (Zhu et al., 2026, *Future Internet*). Focuses on structural coordination topologies: centralized, decentralized, and hierarchical, paired with dynamic-adaptive control axes.

### Foundational Architectures and Coordination Patterns
* [MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework](https://www.semanticscholar.org/paper/MetaGPT%3A-Meta-Programming-for-A-Multi-Agent-Hong-Zhuge/792fd55d79d120173e0a944ce6bfe4787239c1d2) (Hong et al., 2023, ICLR). Uses an assembly-line topology encoding human Standard Operating Procedures (SOPs) into structured artifact-passing protocols to reduce hallucination cascades.
* [AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation](https://www.semanticscholar.org/paper/AutoGen%3A-Enabling-Next-Gen-LLM-Applications-via-Wu-Bansal/9ea0757c750ab1222a7442d3485a74d1c526b04c) (Wu et al., 2023). Implements generalized conversable agent topologies supporting pairwise chats, centralized manager hubs, and custom interaction graphs.
* [ChatDev: Communicative Agents for Software Development](https://www.semanticscholar.org/paper/ChatDev%3A-Communicative-Agents-for-Software-Qian-Liu/9474b463654fd92a62c103b21f95aed94b087907) (Qian et al., 2023, ACL). Introduces multi-phase sequential waterfall orchestration using bilateral (dyadic) peer-to-peer chat rounds.
* [CAMEL: Communicative Agents for "Mind" Exploration of Large Language Model Society](https://www.semanticscholar.org/paper/CAMEL%3A-Communicative-Agents-for-%22Mind%22-Exploration-Li-Hammoud/7bf72a3b5fbac8bc0f461780810fbc781c28ef53) (Li et al., 2023, NeurIPS). Establishes autonomous role-playing dyads coordinated via inception prompting without human intervention.
* [OSC: Cognitive Orchestration through Dynamic Knowledge Alignment in Multi-Agent LLM Collaboration](https://www.semanticscholar.org/paper/OSC%3A-Cognitive-Orchestration-through-Dynamic-in-LLM-Zhang-Fan/ed131ad898f1e9ef0b420e4d3f605abfe055b5f3) (Zhang et al., 2025, EMNLP). Uses dynamic alignment networks and adaptive cognitive routing to coordinate agents dynamically rather than via static pipelines.

### Benchmarks, Evaluation, and Failure Analysis
* [Benchmarking Multi-Agent LLM Architectures for Financial Document Processing: A Comparative Study of Orchestration Patterns, Cost-Accuracy Tradeoffs and Production Scaling Strategies](https://arxiv.org/pdf/2603.22651.pdf) (Kulkarni & Kulkarni, 2026). Evaluates sequential pipeline, parallel fan-out, hierarchical supervisor-worker, and reflexive loop topologies, finding supervisor and reflexive loops offer superior error mitigation at higher communication cost.
* [Solving Multi-agent Path Finding as an LLM Benchmark: How, How Good and Why](https://openreview.net/forum?id=8hAxEFRVQT) (Chen et al., 2025). Adapts multi-agent path finding (MAPF) into an LLM benchmark for spatial coordination and collision avoidance.
* [Benchmark Self-Evolving: A Multi-Agent Framework for Dynamic LLM Evaluation](https://arxiv.org/pdf/2402.11443.pdf) (Wang et al., 2024). Multi-agent workflow generating and updating evaluation test suites to avoid static benchmark saturation.
* [SoK: When Safe Agents Fail Together: The Security of Multi Agent LLM Systems](https://arxiv.org/pdf/2609.00595.pdf) (Yang et al., 2026). Systematizes failure analysis across 197 multi-agent pipelines using an Adversary-Interface-Risk (A-I-R) framework, showing emergent collective vulnerabilities in individually safe agents.
* [Adversarial Attacks in Multi-Agent LLM Pipelines: Unveiling Structural Vulnerabilities in Agentic AI Architectures](https://www.semanticscholar.org/paper/Adversarial-Attacks-in-Multi-Agent-LLM-Pipelines%3A-Bappy-Hossain/821025dd4e89d9fb61cc6ae08591bb47caa14abc) (Bappy et al., 2026). Identifies boundary verification failures across inter-agent interfaces (identity, state, intent, content) as the primary cause of pipeline breakdown.
* [AgentLeak: A Full-Stack Benchmark for Privacy Leakage in Multi-Agent LLM Systems](https://doi.org/10.48550/arXiv.2602.11510) (EL Yagoubi et al., 2026). Evaluates coordinator-worker failure modes, showing information leakage propagates predominantly over internal inter-agent channels rather than external outputs.
