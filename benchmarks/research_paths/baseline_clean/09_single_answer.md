#### Foundational Multi-Agent Orchestration Frameworks

- **AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation**
  - **Authors:** Qingyun Wu, Gagan Bansal, Jieyu Zhang, Yiran Wu, Beibin Li, Erkang Zhu, Li Jiang, Xiaoyun Zhang, Chi Wang
  - **Link:** [arXiv:2308.08155](https://arxiv.org/abs/2308.08155)
  - **Key Focus:** Conversational multi-agent orchestration framework where agents communicate via message passing to solve tasks collaboratively.

- **MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework**
  - **Authors:** Sirui Hong, Mingchen Zhuge, Jonathan Chen, Xiawu Zheng, Cheng Hao, Jinlin Wang, et al.
  - **Link:** [arXiv:2308.00352](https://arxiv.org/abs/2308.00352)
  - **Key Focus:** Standard Operating Procedures (SOPs) encoded into multi-agent workflows to structure role assignment, intermediate artifacts, and inter-agent coordination.

- **ChatDev: Communicative Agents for Software Development**
  - **Authors:** Chen Qian, Xin Cong, Wei Liu, Cheng Yang, Weize Chen, Yusheng Su, et al.
  - **Link:** [arXiv:2307.07924](https://arxiv.org/abs/2307.07924)
  - **Key Focus:** Multi-agent waterfall/agile software development process using conversational chat chains between specialized persona agents (designers, coders, testers).

#### Comprehensive Surveys & Architectural Taxonomies

- **A Survey on Large Language Model based Autonomous Agents**
  - **Authors:** Lei Wang, Chen Ma, Xueyang Feng, Zeyu Zhang, Hao Yang, Jingsen Zhang, et al.
  - **Link:** [arXiv:2308.11432](https://arxiv.org/abs/2308.11432)
  - **Key Focus:** Unified taxonomy of agent architecture, covering profiling, memory, planning, action spaces, and multi-agent cooperation paradigms.

- **The Rise and Potential of Large Language Model Based Agents: A Survey**
  - **Authors:** Zhiheng Xi, Wenxiang Chen, Xin Guo, Wei He, Yiwen Ding, Boyang Hong, et al.
  - **Link:** [arXiv:2309.07864](https://arxiv.org/abs/2309.07864)
  - **Key Focus:** System-level survey analyzing single-agent vs. multi-agent orchestration mechanisms, environment feedback loops, and multi-agent interaction dynamics.

#### Advanced Coordination & Topology Optimization

- **More Agents Is All You Need**
  - **Authors:** Junyou Li, Qin Zhang, Yanghua Xiao, et al.
  - **Link:** [arXiv:2402.05120](https://arxiv.org/abs/2402.05120)
  - **Key Focus:** Empirical scaling laws for multi-agent systems, showing how sampling consensus and collaborative agent counts improve reasoning performance over single-agent setups.

- **SquidAgent: Parallelize Wisely, Coordinate Efficiently**
  - **Authors:** Yexiong Lin, Shanshan Ye, Yu Yao, Zhen Fang, Bo Han, Tongliang Liu
  - **Link:** [arXiv:2410.08647](https://arxiv.org/abs/2410.08647)
  - **Key Focus:** Dynamic coordination balancing parallel task execution and sequential validation to minimize latency and token overhead in multi-agent pipelines.

- **Topology-Conditioned Diagnosis of Multi-Agent LLM Failures**
  - **Authors:** Xinwen Liu, Zhuocheng Pan, Isabella Zhu, Jianwei Zhang, Xudong Liu, Tianyu Wo
  - **Link:** [arXiv:2410.10126](https://arxiv.org/abs/2410.10126)
  - **Key Focus:** Identifies communication bottlenecks, cascade errors, and synchronization failures across different multi-agent topologies (star, hierarchical, mesh, chain).
