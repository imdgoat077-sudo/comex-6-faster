Multi-agent orchestration covers foundational frameworks, dynamic collaboration mechanisms, evolving topologies, and formal communication paradigms.

#### 1. Foundational Multi-Agent Collaboration & Surveys
- **[Multi-Agent Collaboration Mechanisms: A Survey of LLMs](https://arxiv.org/abs/2501.06322)**
  * **Focus:** Comprehensive taxonomy of coordination, communication protocols, dynamic role assignment, and task orchestration patterns across state-of-the-art LLM multi-agent systems.
- **[AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation](https://arxiv.org/abs/2308.08155)**
  * **Focus:** Introduces conversable agents, meta-agent orchestration (`GroupChatManager`), and programmable conversation patterns for complex workflows.
- **[ChatDev: Communicative Agents for Software Development](https://arxiv.org/abs/2307.07924)**
  * **Focus:** Demonstrates multi-agent sequential and hierarchical orchestration structured as a software development company using chat chains.

#### 2. Dynamic, Evolving & Meta-Orchestration
- **[Multi-Agent Collaboration via Evolving Orchestration](https://proceedings.neurips.cc/paper_files/paper/2025/hash/f1320d2e2842169c6fc89dcbd80e94d0-Abstract-Conference.html)**
  * **Focus:** Replaces static topologies with an evolving orchestrator that adapts agent configurations, communication graphs, and role specializations dynamically during task execution.
- **[MAS: Self-Generative, Self-Configuring, Self-Rectifying Multi-Agent Systems](https://proceedings.iclr.cc/paper_files/paper/2026/hash/b88318174aad2cc174a4e05ab6bfad80-Abstract-Conference.html)**
  * **Focus:** Investigates meta-agent orchestration teams capable of autonomously designing, evaluating, and self-correcting agent graphs at runtime.
- **[HALO: Hierarchical Autonomous Logic-Oriented Orchestration for Multi-Agent LLM Systems](https://arxiv.org/abs/2505.13516)**
  * **Focus:** Multi-tiered orchestration structure separating high-level task decomposition, mid-level role instantiation, and low-level task execution.

#### 3. Architectural Design, Evaluation & Production
- **[Architectural Design, Not Only Model Intelligence, Governs Multi-Agent LLM Performance](https://arxiv.org/abs/2602.03128)**
  * **Focus:** Benchmarks orchestration architectures (centralized vs. decentralized, hierarchical vs. flat) to quantify how communication topology impacts accuracy and context efficiency.
- **[Beyond the Strongest LLM: Multi-Turn Multi-Agent Orchestration vs. Single LLMs on Benchmarks](https://arxiv.org/abs/2509.23537)**
  * **Focus:** Rigorous empirical evaluation comparing coordinated multi-agent orchestration against monolithic frontier LLMs across complex multi-step reasoning benchmarks.
- **[OSC: Cognitive Orchestration Through Dynamic Knowledge Alignment in Multi-Agent LLM Collaboration](https://aclanthology.org/anthology-files/pdf/findings/2025.findings-emnlp.335.pdf)**
  * **Focus:** Dynamic knowledge alignment and state synchronization across collaborating agents to prevent hallucination propagation and context divergence.
