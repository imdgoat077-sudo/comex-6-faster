Key research papers on multi-agent orchestration split into practical orchestration frameworks and comprehensive architectural surveys.

### Practical Multi-Agent Orchestration Frameworks

- **AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation**
  - **Links:** [arXiv:2308.08155](https://arxiv.org/abs/2308.08155) | [PDF](https://arxiv.org/pdf/2308.08155)
  - **Citations:** ~5,514
  - **Focus:** Introduces conversable agents combining LLMs, human input, and tools to coordinate dynamic workflows.
- **MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework**
  - **Links:** [arXiv:2308.00352](https://arxiv.org/abs/2308.00352) | [ICLR Proceeding](https://proceedings.iclr.cc/paper_files/paper/2024/hash/6507b115562bb0a305f1958ccc87355a-Abstract-Conference.html)
  - **Citations:** ~4,338
  - **Focus:** Encodes Standard Operating Procedures (SOPs) into structured prompt sequences and shared message pools across software engineering roles.
- **ChatDev: Communicative Agents for Software Development**
  - **Links:** [arXiv:2307.07924](https://arxiv.org/abs/2307.07924) | [PDF](https://arxiv.org/pdf/2307.07924)
  - **Citations:** ~2,500+
  - **Focus:** Organizes specialized LLM agents in a waterfall development cycle using chat chains to mitigate hallucinations.
- **CAMEL: Communicative Agents for "Mind" Exploration of Large Language Model Society**
  - **Links:** [arXiv:2303.17760](https://arxiv.org/abs/2303.17760) | [PDF](https://arxiv.org/pdf/2303.17760)
  - **Citations:** ~2,300+
  - **Focus:** Role-playing communicative framework using inception prompting to guide autonomous cooperation between task-specifier and assistant agents.

### Comprehensive Surveys and Architectural Taxonomies

- **[A Survey on Large Language Model Based Autonomous Agents](https://link.springer.com/article/10.1007/s11704-024-40231-1)**
  - **Citations:** 5,525+
  - **Focus:** Foundational taxonomy covering agent profiling, memory, planning, action spaces, and multi-agent social coordination.
- **[Large Language Model Based Multi-Agents: A Survey of Progress and Challenges](https://arxiv.org/abs/2402.01680)**
  - **Citations:** 2,532+
  - **Focus:** Multi-agent profiling, memory architectures, planning mechanisms, communication paradigms, and evaluation benchmarks.
- **[A Survey on LLM-Based Multi-Agent Systems: Workflow, Infrastructure, and Challenges](https://link.springer.com/article/10.1007/s44336-024-00009-2)**
  - **Citations:** 998+
  - **Focus:** Infrastructure, centralized vs. decentralized communication topologies, and collaborative bottlenecks.
- **[Multi-Agent Collaboration Mechanisms: A Survey of LLMs](https://arxiv.org/abs/2501.06322)**
  - **Citations:** 820+
  - **Focus:** Communication structures (P2P, centralized, shared memory), negotiation protocols, and task partitioning.
- **[Beyond Self-Talk: A Communication-Centric Survey of LLM-Based Multi-Agent Systems](https://arxiv.org/abs/2502.14321)**
  - **Citations:** 150+
  - **Focus:** Communication topologies, dynamic message routing, filtering, and consensus-building mechanisms.
- **[A Survey of AI Agent Protocols](https://arxiv.org/abs/2504.16736)**
  - **Citations:** 147+
  - **Focus:** Standardized agent communication protocols, messaging layers, and interoperability runtimes.
