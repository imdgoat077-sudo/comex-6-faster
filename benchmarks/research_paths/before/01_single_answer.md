Selected research papers covering multi-agent orchestration, coordination architectures, parallel execution, and system-level optimization:

#### Foundational Frameworks & Architectural Surveys
* **[A Survey on Large Language Model based Autonomous Agents](https://arxiv.org/abs/2308.11432)**
  * **Focus:** Comprehensive taxonomy of agent architectures, planning strategies, memory systems, and multi-agent cooperation/orchestration patterns.
* **[AutoGen: Enabling Next-Gen LLM Applications via Multi-Agent Conversation](https://arxiv.org/abs/2308.08155)**
  * **Focus:** Conversational orchestration framework allowing developers to define agent roles, human-in-the-loop triggers, and dynamic inter-agent communication topologies.
* **[MetaGPT: Meta Programming for A Multi-Agent Collaborative Framework](https://arxiv.org/abs/2308.00352)**
  * **Focus:** Standard Operating Procedures (SOPs) encoded into multi-agent workflows to coordinate specialized roles (architect, engineer, tester) and reduce communication noise.
* **[ChatDev: Communicative Agents for Software Development](https://arxiv.org/abs/2307.07924)**
  * **Focus:** Multi-phase waterfall-style chat orchestration using iterative communication and peer-review reflection loops.

#### Graph-Based, Dynamic & Workflow Orchestration
* **[WorkflowOps: Learning Agent Collaboration Priors for Multi-Agent Workflow Orchestration](https://arxiv.org/abs/2610.07860)**
  * **Focus:** Formulates orchestration as learning agent collaboration priors to automate dependency graph routing and scheduling.
* **[DHCG: Dynamic Construction of Hierarchical Collaboration Graphs for LLM-Based Multi-Agent Reasoning](https://arxiv.org/abs/2610.07835)**
  * **Focus:** Dynamically constructs hierarchical collaboration graphs during runtime reasoning to adapt agent communication topology to task complexity.
* **[Know the Shape, Find the Fault: Topology-Conditioned Diagnosis of Multi-Agent LLM Failures](https://arxiv.org/abs/2610.10126)**
  * **Focus:** Analyzes communication topology failures (bottlenecks, loops, hallucinations) in complex multi-agent orchestration graphs.

#### Parallel Coordination & Systems Optimization
* **[SquidAgent: Parallelize Wisely, Coordinate Efficiently](https://arxiv.org/abs/2610.08647)**
  * **Focus:** Addresses latency and synchronization overhead by introducing adaptive parallelization and efficient coordination mechanisms across agent swarms.
* **[EdgeAgent: Orchestrating On-Device LLM Inference for End-User Multi-Agent Systems](https://arxiv.org/abs/2610.03394)**
  * **Focus:** System-level scheduling and resource orchestration for concurrent agent execution on unified memory architectures (CPU-GPU).
